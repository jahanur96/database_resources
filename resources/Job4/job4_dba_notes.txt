3. MEMORY AREAS
   Shared (global, one for the whole server):
   - InnoDB buffer pool     : caches table + index pages. This is the biggest and most important area.
   - InnoDB log buffer      : holds redo changes before they are written to the redo log.
   - Table open cache / definition cache : open tables and their structure.
   - Key buffer             : only for MyISAM indexes (small, not used by DeshiMart).
   Per session (one for each connection):
   - sort_buffer, join_buffer, read_buffer, read_rnd_buffer, temp tables (tmp_table_size),
     and the thread stack.

4. BACKGROUND PROCESSES
   MySQL on Windows is ONE process (mysqld.exe) with many THREADS:
   - srv_master_thread       : main InnoDB loop (flushing, merging)
   - io_read / io_write      : read and write data pages
   - page_flush_coordinator  : writes dirty pages from the buffer pool to disk
   - log_writer / log_flusher / log_checkpointer : write and flush the redo log, checkpoints
   - srv_purge_thread        : removes old undo data and deleted rows
   - dict_stats_thread       : updates optimizer statistics
   - buf_dump_thread         : saves/loads the buffer pool list at shutdown/startup
   - event_scheduler         : runs scheduled events
   - one connection thread for each client session
   (SELECT NAME FROM performance_schema.threads WHERE TYPE='BACKGROUND';)
